# План изменений

Живой список: что чиним и меняем, кроме задач больших планов (Plan 1–6).

**Правила ведения**
- Любая ошибка, которая повторилась (второй раз за проект), заносится сюда и чинится окончательно: не обходом, а так, чтобы не возникла снова.
- CI гоняем только локально: `cd web && npm run ci:local`. Перед каждым push в main — зелёный локальный CI.
- Новые пункты дописываются в конец раздела «Открыто». Закрытый пункт переезжает в «Закрыто» с датой, коммитом и способом проверки.
- Файл до 300 строк. Больше — старые закрытые пункты дословно уходят в `docs/ПЛАН_ИЗМЕНЕНИЙ_архив.md`.
